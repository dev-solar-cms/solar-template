Documentation Solar Template

Solar Template est un thème WordPress classique (non block) conçu pour une boutique WooCommerce. Ce site documente la façon dont le thème est construit, configuré et étendu.

Prérequis

  • PHP 8.1 ou supérieur
  • Une installation WordPress (ce dépôt ne contient pas WordPress lui-même)
  • WooCommerce, pour les fonctionnalités boutique (le thème s'active sans lui et affiche une notice d'administration invitant à l'installer — voir Infrastructure)

Par où commencer

Consultez la section Infrastructure pour savoir comment le thème est construit, testé et publié : gestion des dépendances, configuration d'environnement, système de traduction, pipeline de compilation des assets, tables créées à l'activation, et pipeline d'intégration continue.
