Solar Template documentation

Solar Template is a classic (non-block) WordPress theme built for a WooCommerce storefront. This site documents how the theme is built, configured and extended.

Requirements

  • PHP 8.1 or later
  • A WordPress installation (this repository does not include WordPress core)
  • WooCommerce, for the storefront features (the theme activates without it and shows an administration notice inviting you to install it — see Infrastructure)

Where to start

See the Infrastructure section for how the theme is built, tested and released: dependency management, the environment configuration, the translation system, the asset build pipeline, the database tables created on activation, and the continuous integration pipeline.
